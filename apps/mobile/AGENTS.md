# VYMOD mobile (`apps/mobile`)

Expo SDK 58 React Native app. Follow root [`AGENTS.md`](../../AGENTS.md) for governance and architecture.

## Commands (npm workspace)

```bash
npm run mobile:start          # from repo root
npm run test:mobile
npm run typecheck
npm run lint
```

From this directory: `npx expo start`, `npx expo-doctor`, `npx expo install <pkg>`.

## Routing

**Expo Router** file routes live in `apps/mobile/app/` (not `src/app/`). Business logic, design system, and providers live under `apps/mobile/src/`.

## P1 security note

Navigation guards in `src/app/navigation/` are **client-side development controls only**, not production authorization.

## Native / EAS

No EAS project is configured in P1. Native directories are generated by Expo when needed; do not hand-edit `ios/` or `android/` without CNG workflow.
