# Accessibility Standard

**Target:** WCAG 2.2 Level AA for consumer UI.

- Perceivable: contrast, text resize, captions where media exists
- Operable: keyboard/switch access on web; touch targets ≥ 44×44 dp mobile
- Understandable: consistent navigation; errors associated with fields
- Robust: semantic markup; accessible names from i18n

Automated axe/lighthouse gates: **PLANNED** when UI framework selected.

Mobile: follow platform accessibility guidelines (VoiceOver/TalkBack) with localized hints.
