# Testing Standard

## P0

- Governance validator unit tests: `npm test`
- All validators must have negative tests proving rejection

## Future application code

- Unit tests for authZ and validation logic
- Contract tests for SYNQDRIVE client mocks
- Security regression cases in CI
- i18n snapshot tests optional; parity gate is mandatory

## Reporting

Completion reports list pass/fail/skip/NOT_IMPLEMENTED explicitly.

Do not mark compliance controls VERIFIED without evidence artifacts.
