# Compliance Engineering (VYMOD)

Engineering artifacts to support GDPR-oriented privacy by design, ISO/IEC 27001:2022 and 27701:2025-aligned governance, OWASP baselines, and CRA readiness. **Not legal advice** and **not certification evidence** unless marked VERIFIED with attached proof.

## Status legend

| Status | Meaning |
| --- | --- |
| IMPLEMENTED | Control exists in repo/process with evidence |
| VERIFIED | Independently checked (audit, test report) |
| PARTIAL | Started; gaps documented |
| PLANNED | Designed; not built |
| NOT_APPLICABLE | Out of scope with rationale |
| REQUIRES_HUMAN_LEGAL_REVIEW | Needs legal/DPO decision |

Default for new controls: **PLANNED**.
