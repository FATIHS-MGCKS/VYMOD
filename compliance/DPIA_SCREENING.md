# DPIA Screening Checklist

Use before features involving systematic monitoring, large-scale location, or vulnerable subjects.

| Trigger | VYMOD relevance |
| --- | --- |
| Systematic monitoring | Vehicle tracking — **likely DPIA** |
| Sensitive-scale location | Historical routes — **likely DPIA** |
| New technology | Blockchain/on-chain data — assess |
| Deny-list matching | Stalking vectors — review mitigations |

**Outcome labels:** `NO_DPIA_INDICATED` | `DPIA_RECOMMENDED` | `DPIA_REQUIRED` | `REQUIRES_HUMAN_LEGAL_REVIEW`

P0: no vehicle location feature — screening template only (**PLANNED** for product features).
